# TTRPG Campaign Manager

Manage tabletop RPG campaigns in Obsidian: NPCs, locations, factions, session logs, quests, and loot.

## Features

- **New Campaign** – set up campaigns with system, setting, party size, and status
- **New NPC** – create NPC notes with role, location, secrets, and loot
- **New Session Log** – log sessions with summary, cliffhanger, XP, loot, and NPC wikilinks
- **New Quest** – track quests with giver, status, and rewards
- **Campaign Sidebar** – browse NPCs, Sessions, and Quests per campaign
- **Settings** – configure campaigns folder

## Usage

Open the command palette and search for "TTRPG" to access all commands.
