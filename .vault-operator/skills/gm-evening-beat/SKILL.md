# Evening Beat

## Read context

Read only:

1. Today's Journal note
2. `[[Campaign/01 Campaign Rules]]`
3. `[[Campaign/02 Story So Far]]`
4. The active quest linked from today's note
5. At most two recent story-bearing Journal entries

Do not scan the entire vault.

## Workflow

1. Read today's completed tasks and quest result.
2. Draft a 120–180 word completion beat.
3. Add one concrete next-chapter hook.
4. Advance only existing plot threads.
5. Never shame incomplete tasks or low MP.
6. Do not write to the vault yet.

## Output

Return only:

- Completion beat draft
- Next-chapter hook
- Any unresolved thread or missing context

```markdown

# Evening Beat Output

## Completion beat

<120–180 word completion beat>

## Next-chapter hook

<One concrete hook for tomorrow>

## Continuity notes

- Threads advanced: <list or “none”>
- Threads left open: <list or “none”>
- Missing context: <list or “none”>

```

## Write rule

Only after an explicit request:

- Append the beat below `**Story beat:**` in today's Journal note.
- Append one timeline row to Story So Far.
- Do not change `Current arc` or `Active threads`.
- Show exact diffs and wait for approval.
