# Quest Status Update

1. Read today's Journal entry and the linked quest.
2. Ask for the outcome if unclear.
3. Propose only the exact status, frontmatter, or task-list change requested.
4. Never update Hero XP, MP, gold, or quest status without explicit user values.
5. Show the exact diff and wait for approval.
