# Story Continuity Check

Read only Story So Far, the active quest, and the last two story-bearing
Journal entries.

Identify:

- Unresolved threads
- Contradictions
- Stale statuses
- Missing links
- Plot threads that should not advance yet

Do not invent canon. Return findings only.
Do not edit unless explicitly instructed.
