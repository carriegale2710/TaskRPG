# Setup Guide

## 1. Vault Structure
Copy the folder tree from PRD into a new Obsidian vault.

## 2. Install Plugins (order)
1. Templater (template folder: Templates/)
2. Dataview (enable JS queries)
3. QuickAdd
4. Dice Roller
5. Periodic Notes (daily folder: Journal/)
6. Calendar
7. Text Generator (configure AI provider)
8. Life RPG (create hero, 3-5 habits)
9. Atlas VTT (create world map + region pins)
10. Kanban (point at Campaign/03 Quest Board.md)

## 3. Templates
Copy Templates/ folder into vault. Bind GM templates to hotkeys in Text Generator.

## 4. Dataview Dashboard
Paste Campaign/03 Quest Board.md content into your vault's Quest Board.

## 5. Atlas VTT
1. Open Atlas dashboard, create world map
2. Add 3-5 region pins
3. Use Note Pin Tool (P) to pin World/Regions/[name].md
4. Pin active quest notes to specific spots

## 6. Life RPG
1. Create hero
2. Add 3-5 habits
3. Set XP rewards aligned with quest values

## 7. Daily Workflow
Morning (2 min): open daily note, fill MP/energy/capacity/habits, write 1-2 tasks, run GM morning.
During day: work tasks, check habits in Life RPG.
Evening (3 min): mark quest complete, run GM evening, update Atlas pin.
Weekly (10 min): open weekly review, check Dataview, prune stale quests.

## 8. First-Week Validation
- [ ] Filled MP every morning
- [ ] Quest scope matched capacity
- [ ] Story beats referenced prior plot
- [ ] >=1 task on low-MP days
- [ ] Upkeep <=10 min/day
